# Agent workspace

Mode: Operate. Platform: web. Code-led implementation.

## Direction contract

THESIS: A focused agent editor and test bench. Replace the rejected long wall of
forms and panels with one clearly scoped task per view.

OWN-WORLD: Preserve Orbit's emblem, IBM Plex Sans and Mono, and neutral light/dark
foundation. Use the emblem's violet only for the active editing section and tab
indicator. Single-pixel boundaries divide work areas; no stacked generic cards.

STORY: Identify the agent and saved version, edit its identity/behaviour/models,
confirm its OpenRouter key source (agent override or environment default), then test
an input and inspect the resulting decisions.

FIRST VIEWPORT: Compact branded breadcrumb header; identity and version row;
Configuration/Playground/History/Access tabs. Configuration has a narrow section
navigator, one readable editor pane and a save bar. Playground places the input
beside its latest persisted result. Mobile changes to a single column.

FORM: No concept-seed round was conducted. The existing user direction “Vercel
inspired” pins the brand, not this composition. The editor composition is an
implementation choice under the user’s redesign authorization, not an approved comp.
The user requested both a layout and visual-treatment rethink while retaining the
logo, fonts and themes. The signature interaction is editing and testing in separate
views without losing unsaved configuration or pasted input. Controls change state
immediately; the shared button's reduced-motion-aware press feedback remains.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict acted on, and documentation.
