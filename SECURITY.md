# Security policy

Report vulnerabilities privately through [GitHub's security advisory form](https://github.com/timborovkov/orbit/security/advisories/new). Do not open a public issue or pull request containing an undisclosed vulnerability, working exploit, credentials, or private data.

Include the affected feature or commit, impact, reproducible steps using your own or synthetic data, and a way to contact you. Remove secrets from screenshots and logs. Please avoid testing that disrupts other users or third-party services.
